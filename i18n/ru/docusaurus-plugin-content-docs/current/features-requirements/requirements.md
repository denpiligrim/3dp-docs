# Системные требования

- Сервер с Ubuntu или Debian и root-доступом для установщика.
- Docker и Docker Compose; установщик установит их при необходимости.
- Одна или несколько панелей 3x-ui с доступными API инбаундов и Clients. Поддержка протоколов и токенов зависит от версии панели.
- SSH-доступ к промежуточному серверу для настройки relay.
- Сертификат и приватный ключ на соответствующей ноде для TLS-инбаундов.
- Домен при выборе доменного HTTPS для веб-интерфейса. Также доступны HTTP и самоподписанный HTTPS.

Сертификат веб-интерфейса и сертификаты TLS-инбаундов настраиваются отдельно. См. [Установка](../getting-started/installation.md) и [Использование](../getting-started/usage.md).
