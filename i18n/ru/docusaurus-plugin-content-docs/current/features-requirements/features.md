# Возможности

- Несколько нод 3x-ui с авторизацией по токену либо логину и паролю.
- Подписки с постоянными URL, объединяющие подключения нескольких нод.
- Мастер подписок, привязка существующего клиента 3x-ui или создание нового, статистика трафика, лимиты и сведения о сроке действия.
- Отдельные настройки ноды, relay, порта, флага и названия каждого инбаунда.
- VLESS, VMess, Shadowsocks, Trojan, Hysteria2 и внешние ссылки подключений.
- Профили маршрутизации Happ и INCY для обычных и relay-подписок.
- Управление SNI-доменами с импортом, экспортом и автопоиском.
- Фоновая генерация и удаление с повторными попытками, ограничением нагрузки и Журналом операций.
- Ротация с подготовкой новых инбаундов до удаления старых.
- Установка веб-интерфейса по HTTP или HTTPS с Let's Encrypt, собственным либо самоподписанным сертификатом.

Типы подключений и порядок настройки v3.0.0 описаны в разделе [Использование](../getting-started/usage.md).
