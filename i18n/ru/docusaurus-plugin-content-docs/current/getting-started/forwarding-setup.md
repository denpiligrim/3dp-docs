# Настройка перенаправления

Relay перенаправляет трафик с промежуточного сервера на выбранную ноду 3x-ui. Перенаправление работает на **промежуточном сервере**; для настройки через веб-интерфейс требуется SSH-доступ.

## Настройка через интерфейс

В разделе **Relay серверы** добавьте промежуточный сервер по домену или IP, выберите целевую ноду и установите перенаправление. Для домена backend попытается определить IP автоматически. Назначьте relay нужным инбаундам в **Подписках**.

Установка и удаление выполняются в фоне; результаты доступны в **Журнале**. Копируйте URL из **Подписок**, а не ищите переменную `SUB_URL` на relay.

## Ручная установка

На промежуточном сервере замените `IP_ADDRESS` на IP целевой ноды:

```bash
sudo ORIGIN_IP="IP_ADDRESS" bash -c "$(curl -fsSL https://raw.githubusercontent.com/denpiligrim/3dp-manager/main/forwarding_install.sh)"
```

Скрипт настраивает UFW/NAT для TCP и UDP на портах `443`, `8443` и `10000–60000`. Для других фиксированных портов настройте соответствующие правила фаервола и перенаправления отдельно.

## Удаление перенаправления

Используйте веб-интерфейс или выполните от root на промежуточном сервере:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/denpiligrim/3dp-manager/main/forwarding_delete.sh)
```

Скрипт восстанавливает правила UFW из резервной копии при её наличии, удаляет правила перенаправления, отключает IP forwarding, перезагружает UFW и планирует перезагрузку системы. Учитывайте разрыв соединения с промежуточным сервером.
