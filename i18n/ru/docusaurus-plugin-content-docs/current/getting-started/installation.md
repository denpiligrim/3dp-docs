# Установка

Инструкция актуальна для **3DP-MANAGER v3.0.0**. Подготовьте сервер с Ubuntu или Debian, root-доступом и одну или несколько доступных панелей 3x-ui. См. [Системные требования](../features-requirements/requirements.md).

## Быстрая установка

Выполните от root на сервере, где будет работать 3DP-MANAGER:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/denpiligrim/3dp-manager/main/install.sh)
```

Интерактивный установщик при необходимости установит Docker и Docker Compose, затем развернёт PostgreSQL, backend и frontend в `/opt/3dp-manager`.

Выберите HTTP или HTTPS с Let's Encrypt, собственным либо самоподписанным сертификатом. В конце установщик покажет адрес интерфейса, порт, логин и пароль администратора. Войдите по этому адресу и смените пароль в разделе **Настройки**.

## Подключение панелей

После установки добавьте панели 3x-ui в разделе **Ноды**: укажите URL панели и токен либо логин и пароль. Панель может работать на другом сервере или в Docker, если её API доступен приложению. Прежняя команда с `REMOTE_PANEL=true` больше не нужна.

Далее настройте ноды, домены и подписки по [инструкции по использованию](usage.md). Для промежуточного сервера см. [Настройка перенаправления](forwarding-setup.md).

## Проблемы с установкой Docker

Если автоматическая установка Docker не удалась, установите его по [официальной инструкции](https://docs.docker.com/engine/install/) для вашей ОС, затем повторите запуск установщика.
