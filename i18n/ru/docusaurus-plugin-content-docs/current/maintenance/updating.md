# Обновление

## Стандартная установка

Для установки, выполненной скриптом, запустите от root:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/denpiligrim/3dp-manager/main/update.sh)
```

Скрипт создаёт резервную копию БД в `/opt/3dp-manager/backups`, включает миграции и обновляет контейнеры. Сохраните `.env` и `docker-compose.yml` с параметрами существующей установки. Важные резервные копии храните также вне каталога установки.

После обновления до **v3.0.0** проверьте ноды и подписки в веб-интерфейсе. Следите за результатами генерации в **Журнале**. Если операция была прервана перезапуском, перед повторным запуском проверьте её результат на ноде.

## Самостоятельное развёртывание

Обновляйте схему БД вместе с backend. Для фоновой очереди требуется миграция `1793300000000-add-operations`, добавляющая таблицу `operation` и поле `inbound.isPending`.

Стандартная конфигурация Compose использует `DB_SYNCHRONIZE=true`. Если синхронизация отключена, примените миграции с `DB_MIGRATIONS_RUN=true` при обновлении backend. Не запускайте новую версию backend с устаревшей схемой.

Поведение очереди и настройки описаны в [документации фоновых операций v3.0.0](https://github.com/denpiligrim/3dp-manager/blob/v3.0.0/docs/background-operations.md).
