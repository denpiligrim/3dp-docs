**3DP-MANAGER v3.0.0**, released on October 30, 2026, introduces a subscription wizard, 3x-ui client binding, and background operations with a journal. It also adds connection options and improves rotation reliability.

{/* truncate */}

## Subscriptions and routing

- Create subscriptions with the wizard and bind them to existing 3x-ui clients or create clients automatically.
- View traffic statistics, limits, and expiration information.
- Use Happ and INCY routing in both direct and relay subscriptions.

## Background operations and safer rotation

Generation and deletion run in the background. The Journal shows progress, results, and retries. New inbounds are created before old ones are removed, and temporary errors are retried. A failed subscription does not stop the remaining batch.

The queue survives restarts, but a task already running at shutdown is marked interrupted. Check its outcome on the node before launching it again.

## Connections and compatibility

- New VLESS XHTTP GET connection type.
- VLESS WebSocket with TLS.
- Fingerprint selection and configurable certificate paths.
- Improved compatibility with current and legacy 3x-ui client schemas, including fixes for 3x-ui v3.6.0.
- Generation fixes and refreshed light and dark themes.

## Updating

For a standard installation, run as root:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/denpiligrim/3dp-manager/main/update.sh)
```

The updater backs up the database to `/opt/3dp-manager/backups` and updates the containers. Keep `.env` and `docker-compose.yml`. Custom deployments must update the database schema with the backend; the background queue requires migration `1793300000000-add-operations`.

See [Updating](/docs/maintenance/updating) and [Usage](/docs/getting-started/usage) for the full workflow.
