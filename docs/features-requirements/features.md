# Features

- Multiple 3x-ui nodes with token or username/password authentication.
- Subscriptions with permanent URLs combining connections from multiple nodes.
- A subscription wizard, existing 3x-ui client binding or automatic client creation, traffic statistics, limits, and expiration information.
- Separate node, relay, port, flag, and name settings for each inbound.
- VLESS, VMess, Shadowsocks, Trojan, Hysteria2, and external connection links.
- Happ and INCY routing profiles for direct and relay subscriptions.
- SNI domain management with import, export, and automatic discovery.
- Background generation and deletion with retries, load limits, and an operation journal.
- Rotation that prepares new inbounds before removing old ones.
- Web UI installation over HTTP or HTTPS with Let's Encrypt, custom, or self-signed certificates.

See [Usage](../getting-started/usage.md) for connection types and the v3.0.0 setup workflow.
